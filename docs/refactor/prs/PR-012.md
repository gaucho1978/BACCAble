**PR-012 — Krótka sekcja krytyczna odbioru CDC**

Typ: **FIX**. Model: GPT-5.6 Sol / medium. Budżet produkcji: **250 linii**.

Wymagane dokumenty: [kontrakt](../EXECUTION_PL.md), [decyzje](../DECISIONS_PL.md), [akceptacja](../ACCEPTANCE_PL.md).

**Warunki wejścia:** [PR-003](PR-003.md). Bez dodatkowej bramki wejściowej; wymagany odbiór sprzętowy opisano poniżej.

**Problem i oczekiwany rezultat.** Parser nie czeka na USB przy wyłączonych przerwaniach.

**Dozwolone pliki produkcyjne / narzędziowe.** `(nowy)` oznacza plik do utworzenia w tej karcie. Zmiana pliku wspólnego obejmuje tylko wskazaną odpowiedzialność.

- `firmware/ledsStripController/USB_DEVICE/App/usbd_cdc_if.c`

**Dokładny zakres pracy.**

- W krótkiej sekcji przejąć stabilną kopię pakietu; zwolnić slot RX po skopiowaniu, odtworzyć PRIMASK i dopiero parsować.
- Jeżeli cdc_process wywołano przy PRIMASK=1, pozostawić pakiet do następnej iteracji z włączonymi przerwaniami.
- Pozostawić dotychczasowy timeout TX; jego usunięcie to osobna karta.

**Poza zakresem.** Kolejka TX, protokół i powiększanie RX.

**Kryteria akceptacji.** Wszystkie warunki wspólne oraz:

- [ ] PR-012-A1: Parser widzi IRQ włączone przy normalnym wywołaniu.
- [ ] PR-012-A2: RX nadpisujący zwolniony slot nie zmienia lokalnego pakietu.
- [ ] PR-012-A3: V\rV\r nie powoduje nieskończonego oczekiwania z symulacją postępu tick/USB.
- [ ] PR-012-A4: Wejście z PRIMASK=1 nie konsumuje pakietu, nie parsuje i nie włącza IRQ.

**Testy i dowody.** H:pr012, pełne H, B4, L, D i M. Wymagany profil przed akceptacją aktywnej zmiany: **HW-USB**.
