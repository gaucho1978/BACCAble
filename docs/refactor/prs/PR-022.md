**PR-022 — Walidacja ustawień i wynik SAVE&EXIT**

Typ: **FIX**. Model: GPT-5.6 Sol / medium. Budżet produkcji: **250 linii**.

Wymagane dokumenty: [kontrakt](../EXECUTION_PL.md), [decyzje](../DECISIONS_PL.md), [akceptacja](../ACCEPTANCE_PL.md).

**Warunki wejścia:** [PR-021](PR-021.md), [PR-018](PR-018.md). Bez dodatkowej bramki wejściowej; wymagany odbiór sprzętowy opisano poniżej.

**Problem i oczekiwany rezultat.** Nieprawidłowe wartości nie stają się ustawieniami, a błąd flash nie wygląda jak udany zapis.

**Dozwolone pliki produkcyjne / narzędziowe.** `(nowy)` oznacza plik do utworzenia w tej karcie. Zmiana pliku wspólnego obejmuje tylko wskazaną odpowiedzialność.

- `firmware/ledsStripController/Core/Src/setup_menu.c`
- `firmware/ledsStripController/Core/Inc/setup_menu.h`
- `firmware/ledsStripController/Core/Src/setup_menu_entries.c`
- `firmware/ledsStripController/Core/Inc/user_config.h.sample`

**Dokładny zakres pracy.**

- Rozszerzyć walidację deskryptora o typ/range, bez zmiany slotów; PEDAL_MAP_POWER interpretować int8_t, dopuścić −10…10, pozostałe pola według obecnych zakresów.
- Ujednolicić default launch na LAUNCH_ASSIST_THRESHOLD, zachować poprawny zapis jako nadrzędny.
- SAVE&EXIT przy błędzie zostawia menu otwarte i dirty oraz pokazuje SAVE ERROR; po sukcesie dotychczasowe wyjście.

**Poza zakresem.** Nowy format flash i zmiana prawidłowych wartości domyślnych poza korektą nazwy makra.

**Kryteria akceptacji.** Wszystkie warunki wspólne oraz:

- [ ] PR-022-A1: PEDAL values 0xF6/0xFF/0/10 odpowiadają −10/−1/0/10; 11/127/0xF5 odrzucone do default.
- [ ] PR-022-A2: 0xFFFF i out-of-range dla każdego typu dają default, prawidłowy legacy zapis pozostaje.
- [ ] PR-022-A3: LAUNCH_ASSIST_THRESHOLD=150 działa na pustej flash, poprawny zapis 100 nadal daje 100.
- [ ] PR-022-A4: HAL error → SAVE ERROR, dirty i menu otwarte; sukces → wyjście, brak fałszywego komunikatu.

**Testy i dowody.** H:pr022, pełne H, B4, L, D i M. Wymagany profil przed akceptacją aktywnej zmiany: **HW-UI**.
