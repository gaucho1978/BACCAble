**PR-024 — Typy wyników disk_ioctl**

Typ: **FIX**. Model: GPT-5.6 Sol / medium. Budżet produkcji: **250 linii**.

Wymagane dokumenty: [kontrakt](../EXECUTION_PL.md), [decyzje](../DECISIONS_PL.md), [akceptacja](../ACCEPTANCE_PL.md).

**Warunki wejścia:** [PR-003](PR-003.md). Bez dodatkowej bramki wejściowej; wymagany odbiór sprzętowy opisano poniżej.

**Problem i oczekiwany rezultat.** Sterownik wypełnia cały wynik o typie wymaganym przez FatFs.

**Dozwolone pliki produkcyjne / narzędziowe.** `(nowy)` oznacza plik do utworzenia w tej karcie. Zmiana pliku wspólnego obejmuje tylko wskazaną odpowiedzialność.

- `firmware/ledsStripController/Core/Src/diskio.c`

**Dokładny zakres pracy.**

- GET_SECTOR_COUNT zapisuje LBA_t, GET_SECTOR_SIZE WORD, GET_BLOCK_SIZE DWORD.
- Sprawdzać pdrv i buff dla poleceń wymagających danych; zachować CTRL_SYNC/CTRL_TRIM kontrakt aktualnego sterownika.

**Poza zakresem.** Geometria partycji, algorytm zapisu i aktualizacja FatFs.

**Kryteria akceptacji.** Wszystkie warunki wspólne oraz:

- [ ] PR-024-A1: Bufor 0xA5A5A5A5 otrzymuje pełne 0x00000080 dla bieżących 128 sektorów.
- [ ] PR-024-A2: Block size daje 0x00000004, sektor 512.
- [ ] PR-024-A3: Nieobsługiwany pdrv/opcode i NULL wymagany buff → RES_PARERR.
- [ ] PR-024-A4: Znaczniki poza polem wyniku pozostają niezmienione.
