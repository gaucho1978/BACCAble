**PR-025 — Granice i propagacja błędów diskio**

Typ: **FIX**. Model: GPT-5.6 Sol / medium. Budżet produkcji: **400 linii**.

Wymagane dokumenty: [kontrakt](../EXECUTION_PL.md), [decyzje](../DECISIONS_PL.md), [akceptacja](../ACCEPTANCE_PL.md).

**Warunki wejścia:** [PR-024](PR-024.md), [PR-017](PR-017.md). Bez dodatkowej bramki wejściowej; wymagany odbiór sprzętowy opisano poniżej.

**Problem i oczekiwany rezultat.** Błąd jednej strony nie jest ukrywany przez sukces następnej; I/O nie wychodzi poza dysk.

**Dozwolone pliki produkcyjne / narzędziowe.** `(nowy)` oznacza plik do utworzenia w tej karcie. Zmiana pliku wspólnego obejmuje tylko wskazaną odpowiedzialność.

- `firmware/ledsStripController/Core/Src/diskio.c`

**Dokładny zakres pracy.**

- Sprawdzać pdrv, count>0, buff i zakres przez count<=total-sector bez przepełnienia; sprawdzić również granice stron erase.
- Zastąpić listę malloc iteracją po kolejnych stronach i jednym statycznym scratch 2048 B. Reentry → RES_NOTRDY; blokada zawsze zwalniana.
- Pierwszy błąd unlock/erase/program kończy operację; lock po każdej rozpoczętej operacji. Programować półsłowami zgodnie z STM32F0.

**Poza zakresem.** Zmiana zakresu dysku, atomowość FAT i asynchroniczny sterownik flash.

**Kryteria akceptacji.** Wszystkie warunki wspólne oraz:

- [ ] PR-025-A1: sector=total,count=1; count=0; ogromny count → błąd bez dostępu/erase.
- [ ] PR-025-A2: Zapis przekraczający granicę strony zachowuje nietknięte sektory obu stron.
- [ ] PR-025-A3: Błąd pierwszego programowania powoduje RES_ERROR i brak prób następnej strony.
- [ ] PR-025-A4: Brak malloc/free; reentry i każda ścieżka błędu zwalniają stan zajętości; raport RAM/.su.

**Testy i dowody.** H:pr025, pełne H, B4, L, D i M. Wymagany profil przed akceptacją aktywnej zmiany: **HW-FLASH**.
