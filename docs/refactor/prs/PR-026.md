**PR-026 — Prawdziwy kontrakt tylko do odczytu USB MSC**

Typ: **FIX**. Model: GPT-5.6 Sol / medium. Budżet produkcji: **250 linii**.

Wymagane dokumenty: [kontrakt](../EXECUTION_PL.md), [decyzje](../DECISIONS_PL.md), [akceptacja](../ACCEPTANCE_PL.md).

**Warunki wejścia:** [PR-024](PR-024.md). Bez dodatkowej bramki wejściowej; wymagany odbiór sprzętowy opisano poniżej.

**Problem i oczekiwany rezultat.** Host widzi dysk jako read-only, zgodnie z rzeczywistą obsługą WRITE.

**Dozwolone pliki produkcyjne / narzędziowe.** `(nowy)` oznacza plik do utworzenia w tej karcie. Zmiana pliku wspólnego obejmuje tylko wskazaną odpowiedzialność.

- `firmware/ledsStripController/USB_DEVICE/App/usbd_storage_if.c`

**Dokładny zakres pracy.**

- STORAGE_IsWriteProtected_FS zwraca ochronę zapisu, zachować odrzucanie STORAGE_Write_FS.
- Sprawdzać LUN/zakres odczytu i gotowość zgodnie z diskio; GetCapacity używa tego samego źródła geometrii.
- Nie blokować wewnętrznego zapisu firmware przez FatFs.

**Poza zakresem.** Włączenie zapisu z hosta i formatowanie dysku.

**Kryteria akceptacji.** Wszystkie warunki wspólne oraz:

- [ ] PR-026-A1: Inquiry/capacity i read działają dla prawidłowego LUN.
- [ ] PR-026-A2: Host otrzymuje write-protected, Write nie programuje flash.
- [ ] PR-026-A3: Read poza zakresem daje błąd bez memcpy.
- [ ] PR-026-A4: Legalny wewnętrzny disk_write nadal działa w teście.

**Testy i dowody.** H:pr026, pełne H, B4, L, D i M. Wymagany profil przed akceptacją aktywnej zmiany: **HW-FLASH**.

Dozwolone artefakty: `tests/host/test_pr026.c`, odpowiadające atrapy w `tests/host/stubs/pr026/`, dane w `tests/fixtures/pr026/` i wyłącznie rejestracja tego testu w `tests/host/Makefile`.  Raport: `docs/refactor/evidence/PR-026.md`; rejestr: tylko wiersz PR-026 w `STATUS_PL.md`.
