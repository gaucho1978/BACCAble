Wymagane dokumenty: [kontrakt](../EXECUTION_PL.md), [decyzje](../DECISIONS_PL.md), [akceptacja](../ACCEPTANCE_PL.md).

**Warunki wejścia:** [PR-028](PR-028.md). Bez dodatkowej bramki wejściowej; wymagany odbiór sprzętowy opisano poniżej.

**Problem i oczekiwany rezultat.** Zaimplementować D06 bez podłączania do działającego menu.

**Dozwolone pliki produkcyjne / narzędziowe.** `(nowy)` oznacza plik do utworzenia w tej karcie. Zmiana pliku wspólnego obejmuje tylko wskazaną odpowiedzialność.

**Dokładny zakres pracy.**

- Stany IDLE/QUEUED/WAIT_REPLY/COOLDOWN, token lokalny, ECU/DID/parameterId/viewGeneration i znaczniki czasu.
- API request, on_tx_started, on_frame, cancel_view, tick; wyniki READY/REJECTED/TIMEOUT/NEGATIVE oraz wartość tylko pod właściwym ID.
- Walidacja PCI/SID/DID/ECU i terminów D06; stan resetowalny do testów, bez HAL i bez dynamicznej alokacji.

**Poza zakresem.** Integracja CAN/menu, nowe usługi i automatyczne ponawianie.

**Kryteria akceptacji.** Wszystkie warunki wspólne oraz:

- [ ] PR-029-A3: Timeout queue/response po 500 ms i cooldown 500 ms działa przy overflow timera.
- [ ] PR-029-A4: Zły PCI/DLC/SID, negative 0x7F22 i NRC78 mają dokładny wynik; tylko poprawna 0x62 z DID daje wartość.
