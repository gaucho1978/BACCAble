**PR-035 — Codec snapshotu i wybór ważnej kopii**

Typ: **NEW_MODULE**. Model: GPT-5.6 Sol / medium. Budżet produkcji: **400 linii**.

Wymagane dokumenty: [kontrakt](../EXECUTION_PL.md), [decyzje](../DECISIONS_PL.md), [akceptacja](../ACCEPTANCE_PL.md).

**Warunki wejścia:** [PR-028](PR-028.md), [PR-022](PR-022.md), [PR-023](PR-023.md). Bez dodatkowej bramki wejściowej; wymagany odbiór sprzętowy opisano poniżej.

**Problem i oczekiwany rezultat.** Format D09 jest przetestowany na hoście, jeszcze bez zapisu flash.

**Dozwolone pliki produkcyjne / narzędziowe.** `(nowy)` oznacza plik do utworzenia w tej karcie. Zmiana pliku wspólnego obejmuje tylko wskazaną odpowiedzialność.

- `firmware/ledsStripController/Core/Src/storage_record.c (nowy)`
- `firmware/ledsStripController/Core/Inc/storage_record.h (nowy)`

**Dokładny zakres pracy.**

- Jawnie kodować little-endian nagłówek/TLV/CRC/commit, bez rzutowania struktury C na bajty.
- Walidować magic, wersję, rolę, długości, duplikaty, CRC i commit; wybierać A/B po generacji według D09.
- Nieznane TLV zachowywać przy aktualizacji; przekroczenie pojemności zwraca błąd bez częściowego wyniku.

**Poza zakresem.** HAL, migracja runtime, nowe klucze poza D09.

**Kryteria akceptacji.** Wszystkie warunki wspólne oraz:

- [ ] PR-035-A1: CRC wektora '123456789' =0xCBF43926; golden bytes całego rekordu są stałe.
- [ ] PR-035-A2: Uszkodzenie każdego pola/kategorii, missing commit i ucięcie payload odrzucają rekord.
- [ ] PR-035-A3: A/B z jedną nieważną kopią wybiera drugą; equal generation→A; wrap→właściwa nowa.
- [ ] PR-035-A4: Roundtrip znanych/nieznanych TLV zachowuje dane; duplikat lub oversize → błąd.

**Testy i dowody.** H:pr035, pełne H, B4, L, D i M. Brak wymaganego testu sprzętowego dla zakresu tej karty; nie zalicza to odbioru późniejszej integracji.
