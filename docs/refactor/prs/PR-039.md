Typ: **INTEGRATE**. Model: GPT-5.6 Sol / medium. Budżet produkcji: **350 linii**.

Wymagane dokumenty: [kontrakt](../EXECUTION_PL.md), [decyzje](../DECISIONS_PL.md), [akceptacja](../ACCEPTANCE_PL.md).

- Nie kasować legacy; zła rola/wersja/CRC A/B nie staje się pozycją.

**Poza zakresem.** Sekwencja parkowania, nowe pozycje i zmiana wartości współrzędnych.
