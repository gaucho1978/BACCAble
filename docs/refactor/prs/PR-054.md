**PR-054 — Rozdzielenie obrazu LED i transmisji DMA**

Typ: **EXTRACT**. Model: GPT-5.6 Sol / medium. Budżet produkcji: **700 linii**.

Wymagane dokumenty: [kontrakt](../EXECUTION_PL.md), [decyzje](../DECISIONS_PL.md), [akceptacja](../ACCEPTANCE_PL.md).

**Problem i oczekiwany rezultat.** Efekty liczą kolory bez HAL, a DMA ma jednoznacznego właściciela bufora.

**Dokładny zakres pracy.**

- Przenieść wyliczanie istniejących obrazów/flag i vumetru do ui_led_frame; nie zmieniać kolorów, geometrii, kolejności animacji.
- W transport_ws2812 pozostawić kodowanie GRB/PWM, start i complete DMA. Bufor aktywny niezmienny do callbacku; nowy obraz trafi do pending.
- Zachować dotychczasowe publiczne API vuMeter jako adapter; inicjalizacja pinów/timera pozostaje z tymi samymi wartościami.

**Poza zakresem.** Naprawy wyglądu animacji, nowe efekty, zmiana timera/pinów i aktywowanie jingle.

**Kryteria akceptacji.** Wszystkie warunki wspólne oraz:

- [ ] PR-054-A2: Kodowanie pojedynczego znanego RGB daje bazową kolejność bitów GRB/PWM.
- [ ] PR-054-A3: Update podczas DMA nie zmienia active; complete umożliwia następny frame.
- [ ] PR-054-A4: Inicjalizacja/wyłączenie/ponowne włączenie działa jak baza; znane podejrzenia animacji zapisane osobno, bez ukrytej korekty.
