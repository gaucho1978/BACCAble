**Dokładny zakres pracy.**

- Najpierw charakterystyka R na aktualnym main: konkretne wejściowe ramki/zdarzenia, wyjściowe bajty/GPIO, wartości stanu i wszystkie użyte progi; pochodzenie każdego fixture zapisane.
- Przenieść funkcję ACC_AUTOSTART z jej obecnym rozpoznaniem zatrzymania i okresami. Nie zmieniać liczenia ramek na timer w tej ekstrakcji; zachować tryby 0/1/2. Wykonanie jest w 0x2FA: carSteadyCounter==200, brakeIntervention_ACC_ESC_ASR, brak fizycznego przycisku, odstęp >500 ms, pięć kolejnych zmienionych ramek. Zachować kod zamiast komentarzy sugerujących inne czasy.
- Prywatny stan statyczny w feature_acc_restart.c; API D01, adaptery w dotychczasowych handlerach. Usunąć tylko przeniesione deklaracje extern; jeżeli inny caller potrzebuje odczytu, użyć getteru. Wymienione pliki wspólne obejmują wyłącznie tę funkcję.
- Zakres własności dotyczy stanu wykonawczego. Ustawienia wskazywane przez SetupParam pozostają u właściciela konfiguracji i są przekazywane jako wejście. Dodatkowe wymienione callery wolno zmienić wyłącznie na odczyt/wywołanie nowego API tej funkcji, bez zmiany ich pozostałej logiki.

**Poza zakresem.** Zmiana zachowania poza wcześniej scalonymi FIX; nowe usługi, piny, ramki, wartości domyślne, retry/timeout albo „poprawki przy okazji”. Nie przenosić innych funkcji z tych samych handlerów.

**Kryteria akceptacji.** Wszystkie warunki wspólne oraz:

- [ ] PR-060-A1: Tryb 0 daje zero symulowanych wznowień.

- [ ] PR-060-A3: Ruch/zmiana stanu ACC/reset dają bazowe anulowanie; długie oczekiwanie nie zmienia okresu.
