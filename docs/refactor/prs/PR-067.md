**PR-067 — Wznawialne przekazanie ustawień po starcie slave**

Typ: **FIX**. Model: GPT-5.6 Sol / medium. Budżet produkcji: **300 linii**.

Wymagane dokumenty: [kontrakt](../EXECUTION_PL.md), [decyzje](../DECISIONS_PL.md), [akceptacja](../ACCEPTANCE_PL.md).

**Warunki wejścia:** [PR-066](PR-066.md), [PR-046](PR-046.md). Bez dodatkowej bramki wejściowej; wymagany odbiór sprzętowy opisano poniżej.

**Problem i oczekiwany rezultat.** Odrzucenie części pakietów inicjalizacji nie kończy przedwcześnie synchronizacji.

**Dozwolone pliki produkcyjne / narzędziowe.** `(nowy)` oznacza plik do utworzenia w tej karcie. Zmiana pliku wspólnego obejmuje tylko wskazaną odpowiedzialność.

- `firmware/ledsStripController/Core/Src/functions_C1baccable.c`
- `firmware/ledsStripController/Core/Src/uart.c`
- `firmware/ledsStripController/Core/Inc/uart.h`

**Dokładny zakres pracy.**

- Zastąpić jednorazowy trigger sześciu ustawień kursorem listy istniejących idempotentnych komend SET. Przesuwać kursor tylko po zaakceptowaniu enqueue.
- Po reset/wake zaczynać od pierwszego ustawienia; pełna FIFO odracza pracę do następnej iteracji, bez pętli busy-wait.
- Stan zdalny UNKNOWN do otrzymania istniejącego raportu, REQUESTED po enqueue. Nie deklarować potwierdzenia pól, których stary protokół nie raportuje.

**Poza zakresem.** Nowy ACK/sequence/CRC, retry toggle i potwierdzenie ECU na podstawie samego UART.

**Kryteria akceptacji.** Wszystkie warunki wspólne oraz:

- [ ] PR-067-A1: Kolejka pełna przy trzecim ustawieniu → po opróżnieniu wysyłane trzecie i kolejne, żadne nie znika.
- [ ] PR-067-A2: Restart w połowie inicjalizacji zaczyna pełną listę od nowa bez toggle.
- [ ] PR-067-A3: Brak raportu slave nie daje fałszywego confirmed.
- [ ] PR-067-A4: Dwa kolejne wake dają tę samą kolejność ustawień i zachowane opóźnienia startowe.

**Testy i dowody.** H:pr067, pełne H, B4, L, D i M. Wymagany profil przed akceptacją aktywnej zmiany: **HW-UART + HW-WAKE**.
