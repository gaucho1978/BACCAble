**PR-070 — Budowanie DEBUG BH/C2 i jednoznaczny wybór roli**

Typ: **FIX**. Model: GPT-5.6 Sol / medium. Budżet produkcji: **250 linii**.

Wymagane dokumenty: [kontrakt](../EXECUTION_PL.md), [decyzje](../DECISIONS_PL.md), [akceptacja](../ACCEPTANCE_PL.md).

**Warunki wejścia:** [PR-001](PR-001.md), [PR-013](PR-013.md). Bez dodatkowej bramki wejściowej; wymagany odbiór sprzętowy opisano poniżej.

**Problem i oczekiwany rezultat.** Deklarowane warianty DEBUG budują się, a błędna konfiguracja nie wybiera przypadkowo roli.

**Dozwolone pliki produkcyjne / narzędziowe.** `(nowy)` oznacza plik do utworzenia w tej karcie. Zmiana pliku wspólnego obejmuje tylko wskazaną odpowiedzialność.

- `firmware/ledsStripController/Core/Inc/globalVariables.h`
- `firmware/ledsStripController/Core/Src/globalVariables.c`
- `firmware/ledsStripController/Core/Inc/compile_time_defines.h`
- `firmware/ledsStripController/Core/Inc/debug.h`
- `scripts/refactor/build-matrix.json`

**Dokładny zakres pracy.**

- Deklarację/definicję FATFS uzależnić od rzeczywistego użycia MSC i jego include; DEBUG CDC nie wymaga FATFS.
- Zachować zgodność obecnych komend -DRELEASE_FLAVOR=X -DX=1, walidować że wybrany token jest jednoznacznie zdefiniowany; brak RELEASE_FLAVOR nadal default CANable.
- Nie używać niezgodnych stałych wszystkich *_FLAVOR=1 równocześnie. Błędna/nieznana rola i konflikt C1/C2/BH/CANable dają #error. Zaktualizować manifest: BH/C2 DEBUG wymagane PASS.

**Poza zakresem.** Zmiana numeracji publicznych CLI bez kompatybilności i wyłączanie DEBUG dla ukrycia błędu.

**Kryteria akceptacji.** Wszystkie warunki wspólne oraz:

- [ ] PR-070-A1: BH/C2 DEBUG kompilują się bez unknown FATFS i z właściwym USB CDC.
- [ ] PR-070-A2: Wszystkie dotychczasowe cztery polecenia wybierają właściwą rolę.
- [ ] PR-070-A3: Nieznana rola i brak wymaganego flavor tokena dają czytelny błąd, bez cichego CANable.
- [ ] PR-070-A4: CANable+DEBUG nadal jawnie odrzucone; BX bez nowych ostrzeżeń.

**Testy i dowody.** H:pr070 (preprocessor cases), H, B4, BX, L, D, M. Wymagany profil przed akceptacją aktywnej zmiany: **HW-USB**.
