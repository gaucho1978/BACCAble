**PR-071 — Dostępność funkcji zgodna z pinami i wariantem**

Typ: **FIX**. Model: GPT-5.6 Sol / medium. Budżet produkcji: **300 linii**.

Wymagane dokumenty: [kontrakt](../EXECUTION_PL.md), [decyzje](../DECISIONS_PL.md), [akceptacja](../ACCEPTANCE_PL.md).

**Warunki wejścia:** [PR-040](PR-040.md), [PR-070](PR-070.md), [PR-018](PR-018.md), [PR-019](PR-019.md). Bez dodatkowej bramki wejściowej; wymagany odbiór sprzętowy opisano poniżej.

**Problem i oczekiwany rezultat.** Zapis ustawień nie uruchamia funkcji wykluczonej przez zasoby sprzętu.

**Dozwolone pliki produkcyjne / narzędziowe.** `(nowy)` oznacza plik do utworzenia w tej karcie. Zmiana pliku wspólnego obejmuje tylko wskazaną odpowiedzialność.

- `firmware/ledsStripController/Core/Inc/setup_menu.h`
- `firmware/ledsStripController/Core/Src/setup_menu.c`
- `firmware/ledsStripController/Core/Src/setup_menu_entries.c`
- `firmware/ledsStripController/Core/Src/main.c`

**Dokładny zakres pracy.**

- Jedna tabela/bitmask capabilities dla roli. Przypisanie PA11 do USB wyklucza LED również przy load flash i akcji menu.
- Niedostępna funkcja ma disabled w deskryptorze i nie uruchamia init/periodic; zachować dane w magazynie bez kasowania.
- Użyć już poprawionych permanent immo/C2 flags; nie tworzyć odmiennej interpretacji tych makr.

**Poza zakresem.** Nowy przydział pinów, automatyczna zmiana sprzętu i ukrywanie opcji tylko dlatego, że eksperymentalne.

**Kryteria akceptacji.** Wszystkie warunki wspólne oraz:

- [ ] PR-071-A1: C1 DEBUG/serial + zapis LED=1 nie uruchamia TIM/DMA LED na PA11.
- [ ] PR-071-A2: Zwykła konfiguracja dopuszczająca LED zachowuje możliwość włączenia.
- [ ] PR-071-A3: Zmiana menu nie obchodzi capability; niedostępne opcje mają czytelny stan.
- [ ] PR-071-A4: Macierz wszystkich istniejących konfliktów daje #error lub runtime disabled zgodnie z tabelą, bez konfliktu peryferiów.

**Testy i dowody.** H:pr071, pełne H, B4, L, D i M. Wymagany profil przed akceptacją aktywnej zmiany: **HW-USB + HW-LED**.
